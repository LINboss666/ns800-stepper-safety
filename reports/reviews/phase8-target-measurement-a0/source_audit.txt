I.2 严格参数合同（REC:702-795）
  spm_validate()（REC:702）是**纯函数**：只读 argc/argv，不碰任何全局状态、寄存器或关闭入口，
  返回一个子命令枚举 + 已解析的 entry id。规则：
    cap/init/stop/status/dump/clear_records/trip => argc 恰为 2
    start <entry>                                => argc 恰为 3，entry 只在三个合法值内
    argc<2 => USAGE；argv[1] 空 => UNKNOWN；空子命令/未知子命令/非法 entry => 各自拒绝
  spm_cmd()（REC:761）四步固定顺序：验证 -> 上下文门（非法上下文**静默** return -1）->
  合法上下文下的"未执行"分支（**可以**打印用法，但仍零动作）-> dispatch。
  返回码合同：0 = 该子命令确实执行；非 0 = 拒绝（未执行）。
  init 的返回值现在如实上报（上一轮 `(void)spm_init_counter(); return 0;` 会把拒绝说成成功）。

  TRCENA 未置位时连 DWT_CTRL 都不读（TRCENA=0 时读 DWT 属实现定义）。
  REC:245 spm_win_note() 起点采 before 两位，REC:313 spm_body_end() 在取 body_end **之前**先采
  after 两位（终点读与计数读之间的顺序是刻意的：先证明使能位成立，再取那个值）。
  窗口内的寄存器读**条数有界**：起点侧最多 5 次（SysTick CTRL、SysTick LOAD、DEMCR、DWT_CTRL、
  CYCCNT），终点侧最多 5 次；没有等待、没有循环、没有打印、没有锁。
  REC:350 spm_eval() 是唯一的裁决点（反向家族一注入的就是这一处）：
    counter_status != OK            => SPM_IV_COUNTER_NOT_OK
    gates 缺 SPM_GT_ALL_MASK 任一位 => SPM_IV_GATE_LOST   (0x0800)
    body_end == body_begin          => SPM_IV_NO_PROGRESS (0x0080)   0 差值不是 0 耗时
    body_end  <  body_begin         => SPM_IV_COUNTER_WRAPPED（独立锚点，家族一不动它）
  四条判据都保留原始 pre/body_begin/body_end/post 与 invalid_reason，不做单一归因。

I.4 历史 COUNTFLAG 退役（复审 A0-02b）
  起点读（REC:264 附近）本来就会把历史 COUNTFLAG 读清；上一轮随后又据此置 SPM_IV_FLAG_PRE，
  等于用"主体开始之前"的事件否定当前主体。r1 起：
    - SPM_IV_FLAG_PRE 从 invalid_reason 退役（头文件保留 0x0004 的退役说明）；
    - SPM_GD_FLAG_PRE_SET 仍逐条留档（主机链断言 r1 全批记录里 0x0004 出现次数 = 0）；
    - 主体内真发生的重装仍由终点读判 RELOAD_IN_BODY，且 TMA23 把"历史旗 + 真重装""历史旗 +
      回绕""历史旗 + 配置漂移"三种负向一起重新断言，防止正向修法把检测器弄瞎。

I.5 能力检查生命周期（复审 A0-02a 的另一半）
  REC:467 spm_quiescent()：state==IDLE 且 in_flight==0 且 cursor==0 且 guard_depth==0。
  REC:476 spm_init_counter() 把该判据放在**任何 PPB 访问与任何缓存改写之前**，不满足就拒绝，
  因此不会读清在途那次记录的起点旗，也不会让一条记录混用两次能力检查。
  控制面合同（写进 sp_measure_a0.h 的头注释）：命令侧只由**单个 msh 控制台会话**调用
  （rtconfig 的 tshell 只有一个控制台），静止态由该控制者维持；与业务线程/ISR 并发的部分只有
  spm_open/win_note/body_end/publish 四个叶子。

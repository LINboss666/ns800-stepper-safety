## 变更历史

### 2026-10-22/23 · Phase 8：安全输入数据语义一致性修正（`phase8-safety-data-semantics`，离线，未上板）

- **要解决的三处语义错位**：① `sensor_service → blackbox → 状态输出` 仍把 `PC.6` 叫 `estop`，
  而它是 `TMC_ENN` 被动反馈（MCU 没有独立急停输入 GPIO，不能由电平反推切断原因）；
  ② 限位宏关闭（目标配置）时 `valid_safety` 要求"四路全解析成功"，导致整组安全采样被误标 N/A；
  ③ 每条记录无法区分**活动状态 / 采样有效性 / 原始电平**，旧记录会被按新语义默默解释。
- **传感器帧**：字段 `estop` → **`enn_feedback`**；新增 `sai_active`（只由配置决定：OFF=`0x9`、ON=`0xF`，
  **不因解析或采样失败而缩小**）与 `sai_valid`（**每帧重算**，只有 `safety_pin()` 解析成功且
  `rt_pin_read()` 严格等于 `PIN_LOW/PIN_HIGH` 才置位 —— 旧的 `rt_pin_read(p)?1:0` 会把 -1/2 之类
  非法读数当成有效 HIGH）；`valid_safety` 重定义为"活动输入本帧全部读到"的聚合位，
  **不是**保护就绪/安全电平/线路完整性证明。OFF 时两路限位连 `safety_pin()` 都不调用（不解析、不读、
  不配置、无 IRQ），显示 `DISABLED_BY_CONFIG`；活动但读不到显示 `INVALID_NO_SAMPLE` 并保留旧值仅供调试。
- **黑匣子**：`bb_frame_t` 用两掩码替换未使用的 `valid_safety` 聚合副本（**仍 48B/帧**，编译期断言）；
  电平 + active + valid 从**同一源帧**传递，落盘时不重算；`record.flags` 在同一 32 位内新增
  `15:12 active`、`27:24 valid`、`31:28 应用语义版本=1`（`fault_code`/`motor_state`/`safety_state`/
  `NS_VALID_*` 位置与职责未重排）；`blackbox_dump` 按**记录自身版本**分派：V1 逐路标注可读性、
  版本 0 = `LEGACY_UNVERSIONED`（bit8 的 ESTOP/ENN 角色与可读性不可追认，只留 raw）、
  其他 = `UNKNOWN_SCHEMA`（绝不默认成 V1）。旧记录不迁移、不重写、不清空。
  **外层存储格式未动**：`ns_storage.c` 零改动，`ns_fault_sample_t` 仍 48B（`offsetof(flags)=44`，
  页面内偏移 56 = 12B 记录头 + 44），页长/CRC/提交协议/分区不变。
- **接口清理**：删除 `project_board.h` 中只为该遗留模块保留的 `PIN_NAME_ESTOP` 别名（全仓已无生产
  消费者）；`FAULT_ESTOP`/`SAFETY_ESTOP` 等历史事件与故障码枚举**原样保留**，未做全局文本替换。
- **验证（全部真执行）**：新链 `bash tests/host/run_safety_data_semantics.sh` 真编译
  `sensor_service.c` + `blackbox.c`（GPIO/RT 原语/其他传感器/电机/状态/`ns_log` 为显式可注入桩，
  存储是内存环，线程不真起），`off_target` 21 例、`on_target` 20 例（`SD05b` 只对 OFF 有意义）
  全部 PASS、缺席/重复/未登记=0、runner rc=0；**两项**仓外反向注入（聚合判据退回四路恒真、
  valid 掩码恒等 active）分别命中 `SD01…` 与 `SD07/SD07b/SD10b` 业务失败身份，干净对照通过。
  既有链未放宽：`build_and_run.sh` V1=25 / V2=22（`CHECK_FAIL/BAD_SELFTEST/MISSING_CASE` 全 0，rc=0）、
